# Vide Utilities

A few utilities I've made while working with [Vide](https://centau.github.io/vide/). They've been useful in my own projects, so I figured I'd share them.

## Utils included

- **RenderLayer** - Switches its children into a `CanvasGroup` only while they’re faded, and keeps them in `Frame` the rest of the time.


Feedback and PRs are welcome!

If you come across any bugs, feel free to create an issue!
